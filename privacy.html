Who operates this client

Rclone Google Drive is operated by Chi Hou Tam (chtam22@gmail.com). It is a personal OAuth client for rclone, an open-source program the operator runs on computers they control. It is a personal configuration, independent of the rclone project.

The client is used with the operator’s own Google account so rclone can copy, sync, and manage files in that account’s Google Drive.

Google user data accessed

When the operator grants access, the client can use these Google OAuth scopes:

  • Google Drive files

    See, create, change, and delete files and folders in the connected Google Drive.

    https://www.googleapis.com/auth/drive

  • Google Drive metadata

    Read file and folder metadata, including names, sizes, and modification times.

    https://www.googleapis.com/auth/drive.metadata.readonly

  • Google Docs

    View and manage Google Docs so document contents can be exported and updated during a sync.

    https://www.googleapis.com/auth/docs

The client does not request access to Gmail, Google Calendar, Google Contacts, or other Google products outside Drive and Docs.

How that data is used

Google user data is used to provide the operator’s file sync:

  • List files and folders in the operator’s Drive.
  • Download file contents to a computer the operator controls.
  • Upload new files, update existing files, and delete files when the operator runs a command that does so.
  • Read metadata to decide which files have changed.
  • Export and update Google Docs when a sync includes those documents.

Google user data is not used for advertising, is not sold, and is not used to build profiles of anyone other than the operator acting on their own account.

Where that data is stored

Drive files remain in the operator’s Google account. Copies that rclone downloads are stored on disks the operator chooses, such as a personal computer or another machine the operator administers.

After consent, Google issues a refresh token. rclone stores that token in its configuration file on the operator’s computer. The OAuth client secret is kept in the operator’s Google Cloud project and in that same local configuration. This website does not store the token or the client secret.

Sharing

Google user data is transferred to Google, as part of Drive API calls, and to computers the operator controls. The only person who uses this client is the operator, working with their own files. There is no separate staff or support team with access to those files.

The operator does not sell Google user data and does not transfer it to third parties for their own purposes. A transfer can still happen if the law requires it, or if it is needed to prevent a security incident affecting the operator’s account or machines.

Limited Use

Rclone Google Drive’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

This website

These pages describe the client and this policy. The site does not ask visitors to sign in, does not set cookies, and does not use analytics. It does not receive or store Google user data. Loading a page does not send the visitor’s Drive contents anywhere.

Retention and deletion

Files stay in Google Drive until the operator deletes them there, and local copies stay on the operator’s disks until the operator deletes them. Metadata is kept only as part of those files and of rclone’s local configuration.

The operator can remove this client’s access at any time from Google Account third-party access. Revoking access stops new API calls. The operator can also delete the saved token from the local rclone configuration. Copies already downloaded remain until the operator deletes those files.

Security

The operator keeps the rclone configuration, including the refresh token and client secret, on machines they control and does not publish those values. This website will never ask for a client secret, a refresh token, or a Google password.

Children

This client and this website are for the operator’s own use. They are not directed at children, and the operator does not knowingly collect personal information from children.

Changes

If the way this client handles Google user data changes, this page will be updated and the effective date above will change. The current version is always the one published at this URL.
