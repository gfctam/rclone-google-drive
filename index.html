What this client does

rclone is an open-source program that runs on a computer the operator controls. This client is the OAuth application that lets that program talk to the Google Drive API. The operator uses it to back up files, copy folders, and keep a local disk and Google Drive in step.

File contents move between Google Drive and those computers. This website only describes the client. It does not sign people in, and it does not receive Drive files.

The program itself is published by the rclone project. This client is Chi Hou Tam’s personal configuration and is independent of that project.

Permissions it asks for

When the operator connects their Google account, Google shows a consent screen for the scopes below. The client does not request Gmail, Calendar, or Contacts.

  • See, edit, create, and delete Drive files

    List folders, download files, upload files, update files, and delete files when the operator runs a command that does so.

    https://www.googleapis.com/auth/drive

  • View Drive file metadata

    Read names, sizes, modification times, and other metadata used to decide what needs to sync.

    https://www.googleapis.com/auth/drive.metadata.readonly

  • See and manage Google Docs

    Export and update Google Docs so a sync can include document contents, not only the Drive file entry.

    https://www.googleapis.com/auth/docs

Who it is for

Chi Hou Tam, connecting Chi Hou Tam’s own Google account. If a Google consent screen sent you here and the account is not yours to manage as the operator, decline the prompt.

How Google user data is handled

  • Access. Drive files, Drive metadata, and Google Docs, through the scopes above.
  • Use. Copy, sync, and manage the operator’s own files.
  • Storage. In the operator’s Google Drive and on computers the operator controls. The refresh token stays in the local rclone configuration.
  • Sharing. With the operator’s own machines. The client does not sell Google user data and does not use it for advertising.
